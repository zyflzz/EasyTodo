# EasyTodo · 极简待办清单

一个**零依赖、离线优先、双击即用**的本地待办清单应用。无需安装、无需构建、无需联网——用 Edge 或 Chrome 直接打开 `EasyTodo.html` 即可开始（或先运行 `setup.bat` 一键配置桌面快捷方式）。追求极致的启动速度与响应速度，在颜值和交互细节上下足功夫。

## 一、这是什么？有哪些功能？

EasyTodo 是一个以「日」为单位管理待办的个人清单工具，核心特性：

### 清单管理
- **增删查改**：输入框回车即添加，点击铅笔行内编辑（或双击条目），删除后 5 秒内可通过 Toast 撤销
- **顺延到今天**：翻到过去的日期，未完成的待办可逐条「移到今天」，或通过进度条右侧按钮一键全部移入（创建时间保持不变，操作后可撤销）
- **历史锁定与补记**：过去的日期默认锁定——不能新增待办、已完成任务不可取消勾选；开启「补记模式」后可为过去补录已完成的待办，并用滚轮手动指定创建时间与完成时间；勾选过去未完成的任务、或重新勾选已取消的任务时，同样需用滚轮指定完成时间（精确到时分，秒/毫秒记为 0，完成时间不能早于创建时间）
- **勾选完成**：打勾描边动画 → 条目置灰加删除线 → 平滑滑动到「已完成」分组之后（FLIP 动画）
- **喝彩动画**：勾选完成瞬间撒出彩纸并飘出表情（🎉✨👏🎊）；完成当天全部待办时升级为更大规模的撒花
- **进度指示**：顶部进度条实时显示当日完成比例

### 四种日历视角
| 视图 | 内容 |
|---|---|
| 日视图 | 当日清单 + 输入框（主界面） |
| 周视图 | 7 列概览，每列显示待办芯片与完成进度 |
| 月视图 | 42 天网格，每日最多预览 3 条，完成数以打勾徽标显示 |
| 年视图 | 12 个迷你月历，热力格展示每日待办密度 |

视图间通过顶部 Tab 或 `1-4` 快捷键切换，上下周期用 `←` `→` 翻转。

### 主题系统（莫兰迪配色）
共 6 套精心调配的主题，切换时全局颜色平滑过渡：
- 浅色：**亚麻米**（默认）、**豆沙粉**、**鼠尾草**、**晨雾蓝**
- 夜间：**夜·墨**、**夜·雾蓝**

未手动选择主题时自动跟随系统深浅色偏好。

### 数据与存储
- **双层持久化**：浏览器 localStorage 永远兜底 + 可选绑定本地文件夹，数据自动同步为可读的 `easytodo-data.json`
- **树形数据格式（v2）**：按「年 → 月 → 日」三层索引组织，叶子按日期有序，年/月节点带计数聚合
- **导出 / 导入**：随时生成 `easytodo-backup-日期.json` 备份，或从备份恢复（自动兼容旧版扁平格式）
- **全局搜索**：跨日期检索所有待办（`/` 或 `Ctrl/⌘ + K`）

### 工程特性
零依赖（无框架、无构建、无网络请求）、纯静态、脚本 `defer` 加载、防抖持久化、事件委托、`prefers-reduced-motion` 与键盘无障碍（`focus-visible`）支持。

## 二、如何使用？

### 启动
1. 用 **Edge 或 Chrome** 打开 `EasyTodo.html`（直接双击即可，`file://` 协议完全支持）
2. 开始添加待办：在日视图顶部输入框输入内容，回车

### setup.bat 是干什么的？（可选，一键环境配置）
普通双击运行即可，**无需管理员权限，可重复执行**（每次运行都会刷新快捷方式）：

| 步骤 | 做什么 | 说明 |
|---|---|---|
| 1/2 | 创建默认数据目录 `data\` | 已存在则跳过，为绑定文件夹后的数据文件做准备 |
| 2/2 | 在桌面创建「EasyTodo」快捷方式 | 目标指向 `EasyTodo.html`，**图标使用 `ico\EasyTodo.ico`**，工作目录为项目根目录；自动获取真实桌面路径（兼容 OneDrive 重定向），创建后会校验文件是否真实生成 |

不想用快捷方式的话，跳过它直接双击 `EasyTodo.html` 完全等效。

### 数据存储（建议首次使用时设置一次）
1. 点击顶栏右侧的 **数据库图标**（数据存储按钮）
2. 点击 **「绑定数据文件夹」**，选择本项目文件夹（推荐）或任意你想存放数据的位置
3. 此后所有增删改查会自动同步写入数据文件，可通过 **「打开文件夹」** 随时查看

**跨会话授权说明**：出于浏览器安全策略，`file://` 页面的文件夹授权无法跨会话持久。新版已做无感处理——打开页面后**任意点击一次**（点标签、点输入框均可）即自动恢复授权，Toast 提示「数据文件夹已连接」；在浏览器授权弹窗中选择「**每次访问时允许**」的部分版本可以完全免授权。

### 数据文件详情（easytodo-data.json）
- **位置**：`<绑定目录>/data/easytodo-data.json`。绑定本项目文件夹时即 `d:\...\EasyTodo\data\easytodo-data.json`；直接绑定 `data` 文件夹也可以，应用会自动识别（不会产生 `data/data` 嵌套），两种绑法落点相同
- **生成时机**：绑定文件夹后立即创建；此后每次增删改查防抖 400ms 自动写入，页面隐藏/关闭前强制落盘
- **内容与编码**：UTF-8 JSON，v2 日期树结构（详见下文「数据格式」），任何文本编辑器可直接查看
- **旧版迁移**：若检测到旧版数据文件位于绑定目录根部（而非 `data/` 子目录），启动时自动迁移到 `data/`，旧文件改写为迁移标记（`"migrated": true`，可手动删除）
- **备份与恢复**：「导出备份」生成 `easytodo-backup-日期.json`（存到浏览器下载目录）；「导入数据」支持 v2 树格式与旧版扁平格式，导入即整体替换
- **不绑定文件夹时**：数据仅存于浏览器 localStorage（键 `easytodo.todos.v1`），功能完整但清理浏览器数据会丢失待办，建议绑定文件夹或定期导出备份

### 快捷键
| 按键 | 功能 |
|---|---|
| `N` | 跳到日视图并聚焦输入框 |
| `1` `2` `3` `4` | 切换 日 / 周 / 月 / 年 视图 |
| `←` `→` | 上一周期 / 下一周期 |
| `T` | 回到今天 |
| `/` 或 `Ctrl/⌘ + K` | 全局搜索 |
| `Esc` | 关闭搜索 / 弹层 |

## 三、项目结构

```
EasyTodo/
├── EasyTodo.html       # 唯一入口：静态外壳 + 防闪白的主题预恢复脚本
├── setup.bat           # 环境配置：创建 data\ 目录 + 桌面快捷方式（带图标）
├── ico/
│   └── EasyTodo.ico    # 应用图标（favicon 与桌面快捷方式共用；来源与替换见下文）
├── data/               # 默认数据文件夹
│   └── easytodo-data.json   # 绑定文件夹后自动生成的数据文件（v2 树结构）
├── css/
│   ├── base.css        # 重置样式、设计令牌（CSS 变量）、6 套莫兰迪主题定义
│   ├── app.css         # 顶栏、工具栏、日视图、搜索浮层、数据面板、Toast
│   └── calendar.css    # 周 / 月 / 年三视图样式 + 响应式适配
└── js/                 # 均以 classic script + defer 加载，ET.* 命名空间通信
    ├── utils.js        # 日期计算、DOM 构建（防 XSS）、FLIP 动画、Toast、
    │                   # ISO 8601 本地时区格式化（isoLocal）、喝彩动画
    ├── store.js        # 数据层：日期桶索引（Map<date, Todo[]>）、
    │                   # 树形序列化/解析、防抖持久化、搜索
    ├── filestore.js    # 文件存储：File System Access API 绑定文件夹、
    │                   # data/easytodo-data.json 读写与旧版迁移、导出/导入
    ├── theme.js        # 主题管理：应用/持久化/跟随系统深浅色
    ├── view-day.js     # 日视图：清单增删改查、勾选完成动效
    ├── view-week.js    # 周视图：7 列概览
    ├── view-month.js   # 月视图：42 天网格（区间查询，单次分组）
    ├── view-year.js    # 年视图：12 迷你月历热力格
    └── app.js          # 装配层：视图路由、主题弹层、数据面板、搜索、快捷键
```

### 模块通信
各模块通过 `window.ET` 命名空间暴露 API（如 `ET.store.add()`、`ET.utils.h()`），加载顺序 `utils → store → filestore → theme → views → app`，由 app.js 统一装配调用，模块间零交叉引用。

### 数据格式（easytodo-data.json，v2）

```json
{
  "version": 2,
  "savedAt": "2026-10-09T17:16:52+08:00",
  "index": {
    "type": "date-tree",
    "tree": {
      "2026": {
        "count": 3,
        "months": {
          "10": {
            "count": 3,
            "days": {
              "09": {
                "count": 3,
                "todos": [
                  {
                    "id": "m8x2k1abc123",
                    "title": "回归测试1",
                    "date": "2026-10-09",
                    "done": true,
                    "createdAt": "2026-10-09T17:16:52+08:00",
                    "completedAt": "2026-10-09T17:16:58+08:00"
                  }
                ]
              }
            }
          }
        }
      }
    }
  }
}
```

- **树形索引**：以日期为键的「年 → 月 → 日」三层结构，叶子（日节点）按日期有序排列，年/月节点带 `count` 聚合——即 B+ 树的索引形态
- **时间字段**：`createdAt` / `completedAt` 为 ISO 8601 本地时区格式，定宽字符串可直接按字典序排序
- **兼容导入**：v1 扁平格式（`{ "todos": [...] }` 或纯数组）、旧毫秒时间戳，读取时自动迁移

### 图标来源与替换
- **来源**：应用图标 `ico/EasyTodo.ico` 取自[阿里巴巴矢量图标库 iconfont](https://www.iconfont.cn/)，作者 **Pudge1996**，[作者主页](https://www.iconfont.cn/user/detail?spm=a313x.search_index.0.d214f71f6.a36a3a81Rodd0R&uid=200154&nid=kkxEzm7HSVJs)
- **替换为自己的图标**：准备一个 `.ico` 文件，**重命名为 `EasyTodo.ico`**（文件名必须一致），直接覆盖 `ico/EasyTodo.ico` 即可——页面 favicon 与桌面快捷方式都读取这一路径，无需改任何代码
- 替换后生效提示：
  - 页面标签图标：浏览器对 favicon 缓存较顽固，按 `Ctrl + F5` 强制刷新或重开标签页
  - 桌面快捷方式：Windows 有图标缓存，覆盖 ico 后重新运行一次 `setup.bat` 刷新快捷方式；若仍显示旧图标，删除桌面快捷方式后重跑 `setup.bat`

### 环境要求
- **推荐**：Edge / Chrome（完整支持：文件存储绑定 + 所有动效）
- **最低**：任何现代浏览器可运行核心功能（Firefox / Safari 下仅无法绑定本地文件夹，localStorage 兜底与全部视图主题不受影响）
